# ComicVeil

Android向けのマンガ・コミックビューワーアプリです。
NAS（自宅サーバー）上のファイルをストリーミングで直接閲覧できることを軸に、
「触らなくても快適、触ればもっと自分好みに」をコンセプトに開発しています。

iOS用ビューワーアプリ **Comic Glass** の操作性・設計思想に強くインスパイアされています。
本アプリはその世界観をAndroidでも実現することを目指した個人開発プロジェクトです。

> ✅ **Google Play で製品版を配信中**です（2026年9月開始）。
> 最新のバージョンはストアページをご確認ください。

## 主な機能

| 機能 | 内容 |
|---|---|
| ファイルブラウザ | ローカルフォルダ / NAS（SMB接続）を「場所」として統一的に表示 |
| 検索 | 今見ているフォルダ／HOME内をリアルタイムに名前で絞り込み |
| ストリーミング閲覧（STRモード） | NASのファイルをダウンロードせずに直接閲覧。ZIPは1ページ目から即表示 |
| ダウンロードモード（DLモード） | 複数選択してまとめてローカルに保存（フォアグラウンドサービスで画面オフ中も継続） |
| ページ送り・ズーム | スワイプ・ピンチズーム・ダブルタップズーム（倍率設定可） |
| 見開き表示・見開き分割 | 横長ページを見開きとして表示、または単ページ表示時は自動で左右に分割 |
| 余白削除 | ページ四隅から背景色を判定し、本文範囲だけを切り出して表示 |
| ブックマーク | 任意のページ／リモートのフォルダ・本を登録・一覧からジャンプ |
| 閲覧履歴 | 開いた本を新しい順に一覧表示、タップで続きから再開 |
| 読書状態管理 | 未読／読書中／既読を自動判定・手動変更にも対応 |
| レーティング・カラーラベル | Lightroomライクな★評価・5色のカラーラベル |
| ソート・フィルター | 名前／更新日／レーティングでソート、状態・ラベルで絞り込み |
| サムネイル自動生成 | ローカル・NASどちらのファイルもキャッシュ付きで高速表示 |
| キャッシュの内訳表示 | 設定画面でサムネイルキャッシュの枚数・容量・生成経路の内訳を確認可能 |
| 明るさ調整・画面回転ロック | ビューワー内から直接調整、設定はアプリ全体で記憶 |
| 他アプリからの受け取り | ファイルマネージャー等から「ComicVeilで開く」で直接起動 |
| 本棚表示 | 詳細・簡易に加え、表紙を棚板に並べて眺める第3の表示モード |
| 複数巻アーカイブ | 1つの圧縮ファイルに複数の巻フォルダが入っている場合、巻の一覧画面から選んで開く |
| 外部ファイルの取り込み | クラウドサービス等でダウンロードしたファイルをアプリに取り込むための専用UI |
| バックアップ／復元 | 読書記録・評価/カラーラベル・しおり・NASサーバー設定・アプリ設定を項目別に選んでJSONへ書き出し・復元。NAS接続情報を含める場合はパスフレーズで暗号化 |
| アプリロック | 起動時・バックグラウンド復帰時にPIN／生体認証で解除するまで中身を表示しない |
| 配色テーマ | ダーク／白系をアプリ全体（HOME・設定など）で切り替え可能。ビューワー画面は常にダーク固定 |

## 対応フォーマット

| 形式 | 拡張子 | 状態 |
|---|---|---|
| ZIP / CBZ | `.zip` `.cbz` | ✅ 対応（Shift-JIS・Progressive Loading対応）**※実機で動作確認済み** |
| RAR / CBR | `.rar` `.cbr` | ✅ 対応（RAR4・RAR5とも。RAR5＋日本語ファイル名は位置ベースのフォールバックで対応）**※実機で動作確認済み** |
| 7-Zip | `.7z` | ✅ 対応 |
| PDF | `.pdf` | ✅ 対応 |
| パスワード付きZIP / 7z | `.zip` `.cbz` `.7z` | ✅ 対応（開くとパスワード入力を求める） |
| パスワード付きRAR | `.rar` `.cbr` | ❌ **対象外**（検証環境の制約により非対応。専用メッセージを表示） |
| パスワード付きPDF | `.pdf` | ❌ **対象外**（Android標準PdfRendererに復号手段が無いため非対応。専用メッセージを表示） |

**★形式の判定は拡張子で行います。** 中身と拡張子が食い違うファイル
（RARなのに `.cbz` など）は正しく開けません。

## 技術スタック

| 用途 | ライブラリ・技術 |
|---|---|
| 言語 | Kotlin |
| UI | Jetpack Compose + Material Design 3 |
| 画像表示 | Coil 3 |
| ZIP / 7z 展開 | Apache Commons Compress |
| RAR展開 | junrar（RAR4・日本語ファイル名対応） / libarchive-android（RAR5） |
| パスワード付きZIP・7z | zip4j / Apache Commons Compress（検知・復号とも対応） |
| SMB接続（NAS） | SMBJ |
| データベース | Room（SQLite） |
| アプリロック | androidx.biometric（生体認証）・SHA-256ソルト付きハッシュによるPIN検証 |
| 最小SDK | Android 8.0（API 26） |

## プロジェクト構成

```
app/src/main/java/com/kamneko88/comicveil/
├── data/            # データ層（Room・NAS・ファイル・設定）
│   ├── db/          # 読書位置・ブックマーク・ファイルメタデータ・タイトル
│   ├── nas/         # SMB接続・NASサーバー設定
│   └── backup/      # バックアップ／復元（JSON化・暗号化・マージ）
├── ui/
│   ├── home/        # ファイルブラウザ画面
│   ├── viewer/      # 閲覧画面（ページ送り・ズーム）
│   ├── volumes/     # 複数巻アーカイブの巻一覧画面
│   ├── settings/    # 設定画面
│   ├── backup/      # バックアップと復元の画面
│   ├── history/     # 閲覧履歴画面
│   ├── lock/        # アプリロック（PIN・生体認証）画面
│   ├── theme/       # 配色テーマ（ダーク／白系）
│   └── transfer/    # ダウンロード転送状況画面
├── service/         # ダウンロードのフォアグラウンドサービス
└── MainActivity.kt
```

## ビルド方法

1. Android Studio でこのリポジトリを開く
2. Gradle Sync を実行（`org.tukaani:xz` など依存ライブラリが自動取得されます）
3. 実機または API 26 以上のエミュレータで実行

```bash
git clone https://github.com/kamneko88/ComicVeil.git
```

開発時のコミット規約・バージョニングルールは [`CONTRIBUTING.md`](./CONTRIBUTING.md) を参照してください。
